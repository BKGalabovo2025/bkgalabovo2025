# **App Name**: Galabovo Badminton Club Admin

## Core Features:

- Member Management: Create, read, update, and delete member profiles, including contact information, membership status, and payment history.
- Financial Tracking: Record and track all income sources, including subscriptions, visits, and membership fees. Generate financial reports for specified periods.
- Schedule and Event Management: Manage the monthly schedule, training sessions, competitions, and special events.
- Inventory Management: Track the club's inventory, including racquets, balls, and apparel. Manage stock levels and pricing.
- Report Generation: Automatically generate financial reports and sales documents based on the data from other modules. Also can check the debt report, which will check which member has debts
- Smart Suggestion: The application will include a tool that uses generative AI to make suggestions about optimal member discount rates for new subscription packages or under-performing merchandise items, to achieve club revenue targets.

## Style Guidelines:

- Primary color: Deep Purple (#673AB7) to convey a sense of sophistication and modernity, befitting a well-organized sports club.
- Background color: Very light gray (#F5F5F5), a desaturated shade of the primary purple, offering a clean and unobtrusive backdrop to the app's content.
- Accent color: Soft Lavender (#D1C4E9), an analogous color to the primary, providing contrast for interactive elements and important information.
- Headline font: 'Poppins', sans-serif. Body font: 'PT Sans', sans-serif. 'Poppins' will provide a geometric, contemporary feel, ideal for titles. 'PT Sans' will pair well for body text, adding some warmth and readability to the layout.
- Use modern, minimalist icons to represent different functions and data points.
- Clean and organized layout with clear visual hierarchy to ensure easy navigation and quick access to information.
- Subtle animations for transitions and interactive elements to enhance user experience without being distracting.

# BK Galabovo & Recovery Zone — Обединена платформа за управление

Това е цялостна екосистема за дигитално управление на **Бадминтон клуб "Гълъбово"** и **Recovery Zone** (център за възстановяване). Проектът обединява два самостоятелни потока в единен интерфейс, оптимизирайки административните процеси и потребителското изживяване.

---

## 🌟 Визия и Цели

След успешното сливане на двата проекта, платформата вече функционира като "Sports & Recovery Portal", предлагайки:

1. **Дигитална администрация:** Пълна автоматизация на членството, финансите, присъствията и инвентара.
2. **Професионално възстановяване:** Резервационна система за услуги по възстановяване (Booking & Reservations).
3. **Състезателен мениджмънт:** Генериране на турнирни схеми и автоматизирана ранглиста.
4. **Облачна инфраструктура:** Използване на Firebase и Vercel за хостинг, база данни и автоматизирани задачи.

---

## 🚀 Архитектура и Технологичен стек

Проектът е изграден по най-съвременните стандарти за уеб разработка (базирано на `package.json`):

- **Frontend:** [Next.js 16.2.7](https://nextjs.org/) (App Router, Turbopack) и React 19.2.6.
- **Styling:** [Tailwind CSS 4.3](https://tailwindcss.com/) + Shadcn/ui (Radix UI компоненти).
- **Backend & Database:** [Firebase 12](https://firebase.google.com/) (Firestore, Auth) и Firebase Admin 13.
- **Автоматизация (Vercel):** Интегриран Vercel Cron Job (`/api/cron/check-statuses`) и Vercel Analytics.
- **Интеграции:** Експорт на данни (`exceljs`, `jspdf`, `html2canvas`) и имейл система (`nodemailer`, `react-email`).
- **Quality Control:** Vitest, Playwright, ESLint 10, Stylelint 17, Prettier, Husky.

## 📦 Основни Модули и Услуги

Структурата на проекта (`src/`) е разделена на следните основни бизнес модули:

### 1. БК Гълъбово (Sports Management)

- **Членове и Семейства:** Картотека и управление на свързани семейни профили.
- **Присъствия:** Проследяване на тренировъчна активност (`attendance-service`).
- **Турнири и Мачове:** Генериране на турнирни схеми (`match-generator.ts`), управление на турнири.
- **Ранглиста:** Динамично изчисляване на класирания (`ranking-service.ts`).
- **График:** Court Board за резервации на кортове (`schedule-service.ts`).

### 2. Recovery Zone (Physical Recovery)

- **Резервации (Booking):** Записване на часове за възстановяване.
- **Клиенти:** Управление на пакети и история на посещенията.

### 3. Единен Административен Панел

- **Финанси и Продажби:** Следене на такси, продажби (`sales-service.ts`), ценообразуване (`price-service.ts`).
- **Инвентар:** Следене на наличности и оборудване (`inventory-service.ts`).
- **Отчети:** Генериране на справки (`report-service.ts`).
- **Автоматични напомняния:** Система за известия (`reminder-service.ts`).

## 📖 Как да започнете (GitHub & Локална среда)

Проектът се съхранява в GitHub: `https://github.com/BKGalabovo2025/bkgalabovo2025.git`

1. **Клониране:** `git clone https://github.com/BKGalabovo2025/bkgalabovo2025.git`
2. **Инсталация:** `npm install`
3. **Локален старт:** `npm run dev` (стартира Next.js с Turbopack)
4. **Проверка на качеството:** `npm run check-all` (Lint + Typecheck + Tests)
5. **Деплой на правила:** `npm run deploy:rules` и `npm run deploy:indexes` (към Firebase).

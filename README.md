# 🏸 BK Galabovo & Recovery Zone — Обединена дигитална спортна платформа

Официална уеб платформа и цялостна екосистема за дигитално управление на **СНЦ „Бадминтон клуб Гълъбово“** и Център за физическо възстановяване **„Recovery Zone by ZM“**. Проектът обединява два самостоятелни спортни бранда в единен високоефективен хибриден портал, съчетаващ публичен клубен сайт, център за възстановяване, родителски портал и защитен административен център.

🌐 **Публичен адрес (Production):** [https://bkgalabovo2025.vercel.app](https://bkgalabovo2025.vercel.app)  
📁 **GitHub Repository:** [BKGalabovo2025/bkgalabovo2025](https://github.com/BKGalabovo2025/bkgalabovo2025)

---

## 🌟 Визия и Архитектурни акценти

Платформата функционира като мултитенант **„Sports & Recovery Portal“** с независимо управление на двата клона (`bkgalabovo` и `recoveryzone`), осигурявайки:

1. **Дигитална спортна администрация:** Пълна автоматизация на картотеки, членства, тренировъчни графици, присъствия и инвентар.
2. **Командировки и Състезания (Business Trips):** Автоматизирано генериране и номериране на заповеди за командировка по националната наредба, финансови разчети, дигитални подписи, OCR сканиране на разписки и PDF бланки.
3. **Годишни отчети за дейността:** Интелигентен модул за годишни треньорски отчети с автоматично преброяване на тренировки по месеци, екстракция на турнири, лагери, демонстрации и съпоставяне на спечелени медали.
4. **Професионално възстановяване:** Интерактивна резервационна система за физическо възстановяване, абонаментни пакети и прегледи.
5. **Турнирен и състезателен мениджмънт:** Автоматично генериране на турнирни схеми (Round Robin / директна елиминация) и динамична ранглиста на клуба.
6. **Родителски портал и Публични услуги:** Заявки за документи и служебни бележки, QR верификация на сертификати и ваучери (`/cert/[id]`), спортен календар за родители.
7. **Интерактивни тренировъчни инструменти:** Shadow Trainer с визуализация на корт и звукова сигнализация, Beep Test (протокол за кардио издръжливост) и годишни планове.

## 🚀 Технологичен стек (2026)

Проектът е изграден по най-високите съвременни стандарти за уеб архитектура и бързина:

- **Среда за изпълнение:** Node.js `24.x` LTS.
- **Frontend Framework:** [Next.js 16.4.3](https://nextjs.org/) (App Router, Turbopack, Server Actions, React Server Components).
- **Библиотека за интерфейс:** [React 19.3.0](https://react.dev/) + [Framer Motion 12.43](https://motion.dev/).

- **Backend & База данни:** [Firebase 12.19](https://firebase.google.com/) (Cloud Firestore, Authentication, Cloud Storage) и [Firebase Admin SDK 13.10](https://firebase.google.com/docs/admin/setup).
- **Хостинг и CI/CD:** [Vercel](https://vercel.com/) (Edge Network, Serverless Functions) с автоматизирани GitHub Actions работни потоци за качество и деплой.
- **Интелигентно разпознаване & Експорт:** OCR сканиране чрез `tesseract.js 7.0`, PDF генерация чрез `jspdf 4.2` и `pdf-lib 1.17`, електронни таблици чрез `exceljs 4.4` и графичен подпис чрез `react-signature-canvas`.
- **Контрол на качеството (QA):**
  - **Vitest 4.1.11:** 83 тестови файла с 555 преминаващи модулни и интеграционни теста.
  - **Playwright 1.63:** End-to-End и визуални регресионни тестове.
  - **Lighthouse CI:** Автоматизирани прецизни одити на всички 213 страници (Desktop и Mobile) с интелигентно диференциално кеширане за гарантиране на **100/100** във всички категории (Performance, Accessibility, Best Practices, SEO).
  - **Линтинг и сигурност:** ESLint 10, Stylelint 17, TypeScript 5.8 (строг типчекинг), Knip, Madge, Dependency Cruiser.

## 📦 Основни функционални модули

### 1. БК Гълъбово (Спортен мениджмънт)
- **Картотека на състезатели:** Детайлни досиета, свързани родителски контакти, възрастови групи, медицински прегледи и картотеки към БФБ.
- **Тренировъчен график & Присъствия:** Интерактивен седмичен календар, бързо маркиране на присъствия (`attendance-service`) и аналитични справки за посещаемост.
- **Турнири & Ранглиста:** Организиране на вътрешни и национални състезания, генератор на срещи (`match-generator.ts`), директно въвеждане на резултати и динамично обновяване на ранглистата (`ranking-service.ts`).
- **Специализирани тренировки:** Интерактивен Shadow Badminton треньор с визуални кортове, аудио сигнализация и статистика за реакция, както и стандартен Beep Test за физическа издръжливост.

### 2. Командировки и Състезания (Business Trips)
- **Заповеди за командировка:** Пълно съответствие с Наредбата за служебните командировки, автоматично номериране чрез атомарни трансакции на сървъра.
- **Разходен център:** Категоризиране на разходи (дневни, пътни, нощувки, съдийски такси), OCR автоматично извличане на суми и дати от касови бележки и фактури.
- **Дигитални подписи и бланки:** Двустранен подпис от треньор и ръководител, експорт в официален двустранен А4 PDF формат.

### 3. Годишен отчет за дейността
- **Автоматично преброяване на тренировки:** Месечна статистика за провежданите тренировки през годината (Януари – Декември).
- **Интелигентна екстракция:** Автоматично разпознаване на организирани събития в зала „Енергетик“, летни спортни лагери, демонстрационни събития („Спорт без отпадъци“, „Be Active“).
- **Съпоставяне на медали:** Свързване на класирания от състезания с участвалите състезатели на клуба за прецизен отчет на отличията.

### 4. Recovery Zone (Център за възстановяване)
- **Онлайн резервации:** Избор на специализирани възстановителни процедури, масажи, пресотерапия и сауна.
- **Абонаменти & Пакети:** Проследяване на брой оставащи посещения и валидност на клиентски карти.
- **Оценки и отзиви:** Публичен модул за проверени клиентски отзиви.

### 5. Административен център, Финанси & Склад
- **Търговска и нетърговска дейност:** Разделно отчитане на членски внос, такси, наеми и продажби на спортна екипировка.
- **Складово стопанство:** Проследяване на наличности (ракети, пера, екипи, аксесоари), автоматично изписване при продажба.
- **Справки & Анализи:** Финансови баланси, графики за приходи и разходи (`recharts`), експорт в Excel и PDF.
- **Сертификати & Ваучери:** Генератор на поименни сертификати и подаръчни ваучери с защитен QR код и публична страница за верификация (`/cert/[id]`).

## 🛠️ Инструкции за разработка и стартиране

### 1. Клониране на хранилището
```bash
git clone https://github.com/BKGalabovo2025/bkgalabovo2025.git
cd bkgalabovo2025
```

### 2. Инсталиране на зависимостите
```bash
npm install
```

### 3. Настройка на променливите на средата
Създайте файл `.env.local` в главната директория с необходимите ключове за Firebase и имейл нотификации:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=bkgalabovo2025.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=bkgalabovo2025
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=bkgalabovo2025.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password
```

### 4. Локално стартиране (Development)
```bash
npm run dev
```
Приложението ще се зареди на `http://localhost:3000` (с Turbopack компилатор).

### 5. Контрол на качеството (Quality Assurance)
```bash
# Пълен пакет проверки: Lint + TypeScript + Circular + Tests + Security
npm run check-all

# Само модулни и интеграционни тестове (Vitest)
npm run test

# Проверка на TypeScript типове
npm run typecheck

# Lighthouse одит за качество и бързина
npm run lighthouse
```

### 6. Деплой на правила и индекси (Firebase)
```bash
npm run deploy:rules
npm run deploy:indexes
```
